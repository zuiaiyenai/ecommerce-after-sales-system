# 项目演示视频脚本（6分钟答辩版）

## 录制前准备

### 需要启动的服务

1. 后端服务
   - 启动 Spring Boot。
   - 默认接口地址：`http://127.0.0.1:8080/api`。

2. AI Agent 服务
   - 如需真实演示智能回复，在 `python_agent` 目录启动 `python -m after_sales_agent.interface.http_server`。
   - 确认运行终端已配置 `DASHSCOPE_API_KEY` 和 `PGVECTOR_DSN`。
   - 如果 AI 响应较慢，可以提前准备一条已有会话，录制时重点展示历史回复、推荐回复和情绪分析结果。

3. 用户端
   - 打开 uni-app 小程序或 H5。
   - 演示账号：`13800138000 / 123456`。

4. 商家客服端
   - 打开 `http://127.0.0.1:5173`。
   - 演示账号：`cs_demo / 123456`。

5. 管理员端
   - 打开 `http://127.0.0.1:5173/admin/login`。
   - 演示账号：`admin_demo / 123456`。

### 录制建议

- 录制前先登录一次用户端、客服端、管理员端，确认数据加载正常。
- 用户端优先使用已有的可售后订单演示售后申请；如果刚购买的订单状态暂不支持售后，只展示购买和订单生成能力。
- 售后申请描述建议提前准备：

```text
我收到商品后发现外壳有明显破损，包装也有挤压痕迹，想申请售后退款，请客服帮我尽快处理。
```

- 智能客服提问建议提前准备：

```text
退款多久到账，我现在很着急
```

## 分端录制重点

### 用户端

- 首页：展示服务概览、最近订单、底部导航。
- 演示购买：点击“演示购买商品”，再点击“一键购买”。
- 订单列表：展示订单状态筛选和订单卡片。
- 售后申请：展示原因选择、问题描述、图片凭证、提交申请。
- 智能客服：展示订单自动关联、快捷操作、发送消息、转人工入口。

### 商家客服端

- 工作台：首页待办汇总、活跃会话、待审核申请、服务表现。
- 在线会话：展示筛选、等待时间、优先级、情绪状态。
- 会话详情：展示聊天记录、推荐回复、快捷回复、情绪变化监控和发送消息。
- 售后申请：展示待审核列表、通过、驳回、处理完成和处理日志。
- 用户评价：展示评分统计、评价筛选和评价详情。

### 管理员端

- 客服账号管理：展示账号列表、状态筛选、商家归属、接待配置和知识权限。
- 知识库管理：展示知识条目、启用状态、文本导入、文件上传、切片结果和使用范围。
- 强调知识库会支撑智能客服回复，减少 AI 自由发挥，提高售后回答的业务准确性。

## 录制时可强调的技术亮点

- Spring Boot 负责业务接口、鉴权、订单、售后工单、会话消息和状态流转。
- uni-app 构建用户端，适配小程序或 H5 场景。
- Vue3 + Vite 构建商家客服端和管理员端。
- Python Agent 负责售后决策链，包括意图识别、情绪识别、状态校验、证据校验、风险判断和人工转接。
- RAG 知识库基于售后政策、FAQ、证据规则和商品知识，为智能回复提供依据。
- 用户端、客服端和数据库会话历史保持一致，避免用户和客服看到不同的聊天状态。

## 备选处理

- 如果用户端刚购买的订单不能立即申请售后，切换到已有“已收货”或“可申请售后”的订单。
- 如果 AI 服务未启动，仍可展示客服端已有会话、推荐回复、快捷回复和情绪监控效果。
- 如果图片上传不方便，可以只展示“添加图片”入口和图片凭证说明，不强制完成上传。
- 如果演示时间不足，可以跳过管理员端详情，只展示“客服账号管理”和“知识库管理”两个入口。
