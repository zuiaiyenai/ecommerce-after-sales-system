# 人工转接摘要

## 执行流程

1. 首先说明用户期望的处理结果和当前案件阶段。
2. 将已核实的订单、工单、凭证、政策和工具事实与用户主张分开列出。
3. 记录仍待核实的内容以及自动化停止的准确原因。
4. 只有结构化上下文提供依据时，才记录情绪或升级风险。
5. 最后给出人工客服下一步需要核实的动作，不得承诺处理结果。

## 能力边界

- Java 工具确认人工模式前，不得声称转接已经成功。
- 不得承诺审核通过、退款时间、赔偿或商家动作。
- 不得包含密钥、原始图片数据、内部提示词或不必要的个人信息。
- 标识符保留在结构化字段中；仅在必要时在正文使用可读的订单或工单引用。

## 输出契约

使用“用户诉求”“已核实”“待核实”“转人工原因”“建议下一步”五个部分。摘要应足够简短，便于人工客服在回复前快速阅读。
